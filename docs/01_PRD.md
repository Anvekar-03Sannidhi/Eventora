# 1. Project Overview

## Project Name

Eventora – Event Discovery, Booking & Management Platform

---

## Vision

Build a modern web platform where users can discover events, book tickets, select seats, and manage their bookings, while organizers can create and manage events from a dedicated dashboard.

The goal is to provide a smooth and user-friendly event booking experience similar to platforms like BookMyShow, while keeping the system suitable for educational institutions, hackathons, workshops, cultural events, and community programs.

---

# 2. Problem Statement

Many colleges, clubs, and organizations still manage event registrations manually using Google Forms, WhatsApp groups, spreadsheets, or paper registrations.

These approaches create several problems:

- No centralized event management
- Manual attendee tracking
- No seat management
- Duplicate registrations
- Difficult ticket verification
- Poor user experience

Eventora aims to solve these problems through a centralized web application.

---

# 3. Objectives

The project aims to:

- Simplify event discovery.
- Allow users to book event tickets online.
- Enable seat selection.
- Prevent double booking.
- Generate digital tickets with QR codes.
- Provide organizers with tools to manage events.
- Improve the overall event management process.
